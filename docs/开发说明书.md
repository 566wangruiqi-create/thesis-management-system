# Codex开发说明书：毕业论文管理系统

请你作为本项目的全栈开发助手，帮助我开发一个“毕业论文管理系统”的管理信息系统课程项目。

本系统用于管理信息系统课程设计，目标是模拟高校毕业论文管理的核心流程，但不要做得过于复杂。重点是：流程完整、结构清晰、可以演示、方便讲解。

---

## 一、项目基本信息

项目名称：毕业论文管理系统

项目类型：管理信息系统课程设计

系统目标：实现一个简化但完整的毕业论文管理流程，包括：

1. 用户登录
2. 角色权限
3. 课题发布
4. 学生选题
5. 教师审核
6. 学生提交过程材料
7. 教师审核材料
8. 答辩安排
9. 成绩录入
10. 论文归档

---

## 二、技术栈

请使用以下技术栈：

1. 前端：HTML + CSS + JavaScript
2. 开发工具：VS Code
3. 代码管理：Git
4. 数据库：MySQL
5. 后端：Node.js + Express
6. 前后端通信：RESTful API
7. 前端部署：Netlify
8. 后端部署：Render 或 Railway
9. 数据库连接信息使用 `.env` 环境变量，不要写死在代码中

---

## 三、当前开发顺序

本项目采用“先前端原型，后接后端和数据库”的开发顺序。

开发路线如下：

```text
第一阶段：前端原型，使用 mockData.js 模拟数据
第二阶段：设计 MySQL 数据库 schema.sql 和 seed.sql
第三阶段：开发 Node.js + Express 后端接口
第四阶段：前端从 mockData.js 切换到真实 API
第五阶段：部署前端和后端
```

当前请优先完成：

```text
client 前端原型
```

暂时不要开发后端，不要连接 MySQL。

## 五、系统角色

系统只设置三种角色，避免过于复杂：

1. 管理员 admin
2. 教师 teacher
3. 学生 student

### 管理员权限

管理员可以：

1. 查看系统首页统计
2. 管理学生和教师信息
3. 查看所有课题
4. 查看所有选题申请
5. 安排答辩
6. 录入最终成绩
7. 管理论文归档

### 教师权限

教师可以：

1. 发布课题
2. 查看自己发布的课题
3. 审核学生选题申请
4. 查看自己指导的学生
5. 审核学生提交的开题报告、中期检查、论文终稿
6. 查看答辩安排和学生成绩

### 学生权限

学生可以：

1. 查看可选课题
2. 提交选题申请
3. 查看选题审核结果
4. 提交开题报告
5. 提交中期检查
6. 提交论文终稿
7. 查看教师审核意见
8. 查看答辩安排
9. 查看最终成绩
10. 查看归档状态
